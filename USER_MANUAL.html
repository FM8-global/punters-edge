🏇 PunterEdge User Manual

Overview

PunterEdge is an AI-powered horse racing betting analysis platform. It provides detailed race predictions and betting insights to approved users.

Live App: https://punters-edge-1.onrender.com

Getting Access

For New Users

Step 1: Request Access

  • Send an email to info@fm8.global
  • Subject: "PunterEdge Access Request"
  • Include your email address in the message

Step 2: Wait for Approval

  • The admin will review your request
  • You'll be added to the approved users list (typically within 24 hours)

Step 3: Login

  • Visit https://punters-edge-1.onrender.com
  • Enter your email address
  • Click "Sign In"
  • You're in! No password required.
Note: Only approved users can access PunterEdge. Contact info@fm8.global if you have questions about your approval status.

Login & Dashboard

Logging In

  1. Go to https://punters-edge-1.onrender.com
  2. Enter your email address (the one registered with the system)
  3. Click Sign In
  4. Your session token is automatically saved to your browser

Dashboard Overview

Once logged in, you'll see the Admin Dashboard with two tabs:

Overview Tab (Default)

Shows key statistics and quick actions:

  • Races Today - Number of upcoming races with analysis
  • Predictions - Total AI predictions generated
  • View Predictions - Browse all AI-generated betting recommendations
  • API Reference - Access technical API documentation
  • View Token - Display your authentication token for API use

User Management Tab (Admin Only)

Allows admins to manage user access:

  • Add new approved users
  • View all users and their status
  • Promote users to admin
  • Remove user access

Session Management

  • Your login session lasts 30 days
  • Token is stored in browser storage (private, not shared)
  • Click Logout to end your session immediately
  • Logging out clears your token

Using the App

Viewing Race Predictions

  1. From the Dashboard, click View Predictions
  2. You'll see AI-generated predictions for upcoming races
  3. Each prediction includes:
    • Horse name and race ID
    • AI confidence score (0-100)
    • Odds and betting information

Understanding Predictions

Score Range Confidence Level Recommendation
80-100 Very Strong High confidence prediction
60-79 Strong Good confidence prediction
50-59 Moderate Use with caution
Below 50 Low Filtered out by default

Admin Guide

Admin Responsibilities

Admins manage user access and system configuration. The main admin email is info@fm8.global.

Adding New Users

Step 1: Log into https://punters-edge-1.onrender.com with admin account
Step 2: Click the User Management tab
Step 3: In the "Add New User" section:
  • Enter the user's email address
  • Click Add User
Step 4: The user is now approved and can log in immediately!

Promoting Users to Admin

To give a user admin privileges:

  1. Go to User Management tab
  2. Find the user in the "Approved Users" list
  3. Click Make Admin next to their name
  4. Confirm the promotion
After promotion:
  • User can see the User Management tab
  • User can add new users and manage approvals
  • User can promote other users to admin

Removing Admin Status

To demote an admin (except the main admin):

  1. Go to User Management tab
  2. Click Demote next to the admin's name
  3. Confirm the action
The main admin (info@fm8.global) cannot be demoted or deleted.

Deleting Users

To remove a user from the system:

  1. Go to User Management tab
  2. Click Delete next to the user's name
  3. Confirm the deletion
Deleted users cannot log in. They must be re-added if they need access again.

API Reference

Authentication

All API requests require an authorization token:

curl https://punters-edge-1.onrender.com/bets \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"

Token expires after 30 days.

Main Endpoints

Endpoint Method Purpose
/login POST Get authentication token
/logout POST End session
/bets GET Get all AI predictions
/races GET Get upcoming races
/admin/users GET List approved users (admin)
/admin/users/add POST Add new user (admin)
/docs GET Swagger API documentation

Example: Get Predictions

curl "https://punters-edge-1.onrender.com/bets?min_score=50" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"

Returns predictions with AI scores ≥ 50.

Example: Get Races

curl "https://punters-edge-1.onrender.com/races" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE"

Returns upcoming races with live odds.

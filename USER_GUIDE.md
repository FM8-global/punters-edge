# PunterEdge User Guide

## 🎯 Welcome to PunterEdge

PunterEdge is a professional horse racing prediction and outcomes tracking application powered by real racing data from the PuntersEdge Racing API.

**Live Application:** https://fm8global.pythonanywhere.com

---

## 🚀 Getting Started

### Step 1: Access the Application
1. Navigate to: **https://fm8global.pythonanywhere.com**
2. You will see the Admin Dashboard login page

### Step 2: Admin Login (If You Have Admin Access)
- **Email:** info@fm8.global
- **Password:** admin123
- Click **SIGN IN**

### Step 3: Request Access (New Users)
If you don't have admin access:
1. Click **"Request Access Here"** on the login page
2. Provide your email address
3. An admin will review and approve your request
4. You'll receive a confirmation email with instructions to set your password

## 🐴 Horse Performance Dashboard

The Outcomes Dashboard displays real horse racing data with the following metrics:

### **Performance Metrics**

| Metric | Description |
|--------|-------------|
| **Horse** | Horse name (e.g., Black Thunder) |
| **Wins** | Number of winning predictions |
| **Places** | Number of place finishes |
| **Losses** | Number of losing predictions |
| **Win Rate %** | Success rate (wins / total predictions) |
| **ROI %** | Return on Investment percentage |

### **Example Data**
```
Black Thunder:   48.00% win rate | 18.50% ROI
Silver Flash:    40.00% win rate | 15.20% ROI
Golden Dawn:     36.00% win rate | 14.10% ROI
```

## 🆘 Troubleshooting

### Issue: Page not loading
**Solution:** 
- Refresh the page (F5 or Cmd+R)
- Clear your browser cache
- Try a different browser

### Issue: Can't log in
**Solution:**
- Verify your email and password
- Request access if you don't have an account yet
- Contact an administrator if you've forgotten your password

### Issue: Horse names not showing
**Solution:**
- This is a display issue only - data is still being tracked
- Refresh the page
- Clear browser cache and reload

### Issue: Slow page load
**Solution:**
- Check your internet connection
- Reduce browser tabs/applications running
- Try accessing from a different device

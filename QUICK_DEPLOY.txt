DEPLOYMENT STEPS (5 minutes)
================================================================================

1. UPLOAD THE FIX
   ----------------
   Option A: If using Git
     git add backend/pythonanywhere_wsgi.py
     git commit -m "Add WSGI adapter fix"
     git push origin main

     Then in PythonAnywhere Bash:
     cd ~/punter-edge && git pull origin main

   Option B: Manual upload
     Go to PythonAnywhere Files tab
     Upload pythonanywhere_wsgi.py to /home/fm8app/punter-edge/backend/


2. UPDATE WSGI CONFIGURATION
   -------------------------
   1. Log in to https://www.pythonanywhere.com
   2. Go to "Web" tab
   3. Click on "fm8app.pythonanywhere.com"
   4. Find "WSGI configuration file" section
   5. Click on the file path to edit it
      (Should be something like /var/www/fm8app_pythonanywhere_com_wsgi.py)
   6. Replace the content with:

      -------- START COPY --------
      import sys
      import os

      app_dir = '/home/fm8app/punter-edge/backend'
      if app_dir not in sys.path:
          sys.path.insert(0, app_dir)

      os.environ['API_KEY'] = 'c9edb4f8-4c7f-4a20-b0a5-edbac822e0ec'

      from pythonanywhere_wsgi import application
      -------- END COPY --------

   7. Click "Save"


3. RELOAD THE APP
   ---------------
   1. Still on Web tab
   2. Click the green "Reload [your-app]" button
   3. Wait for message "Reloaded at HH:MM"


4. TEST IT
   --------

   Test Health Check (should always work):
   $ curl https://fm8app.pythonanywhere.com/health

   Expected: {"status":"ok"}


   Test Login (this is what was broken before):
   $ curl -X POST https://fm8app.pythonanywhere.com/login \
     -H "Content-Type: application/json" \
     -d '{"email":"info@fm8.global"}'

   Expected: {"success":true,"token":"...","message":"Welcome..."}

   If you get {"success":false,"message":"Email not approved..."} - GOOD!
   This means the endpoint is working, user just needs to be approved.
